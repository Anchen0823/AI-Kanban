# v0.5 数据备份与 WebDAV

导航的「数据管理」提供本地备份、备份包导入导出、WebDAV 加密上传及恢复。所有管理操作需要本机用户配对；示例工作区不能操作。

## 本地备份与恢复

点击「立即备份」创建 SQLite 一致性快照。备份包含完整工作台数据库，包括用量、会话标识、标题、项目目录、设置，以及已存在的旧记忆／项目等数据；不打包 AI 客户端原始聊天日志或程序文件。

列表显示校验结果，可下载 `.aiccbackup` 包、导入已有包、查看恢复预览。恢复会覆盖整个业务数据库，执行前自动保留当前状态的备份。恢复后的自动同步及自动备份暂停，需要点击「恢复自动运行」。已有云端配置和任务记录保留。

本地数据库副本与普通下载包未加密，请存放于受保护的位置。导入、下载和云端传输单包上限 128 MiB；包中只有固定名称的清单和数据库，没有压缩解包或任意路径提取。旧版本原生目录备份仍能恢复。

恢复先在临时库校验 SQLite 完整性、外键、schema 和迁移，再等待正在运行的写操作结束并切换数据库。切换失败回滚原库；恢复阶段记录仍在时，下次启动优先回滚，不打开半成品。数据库的 `.restore-old` 和 `.restore-journal` 文件不能在恢复期间手动删除。

## 配置 WebDAV

1. 填写已存在且可访问的 HTTPS WebDAV 目录、用户名和网盘应用密码。
2. 设置至少 12 字符的独立备份密码，并在应用之外妥善保存。忘记密码无法解密。修改密码只影响新生成的加密包，旧包仍需原密码。
3. 保存后点击「测试连接」。测试在应用专属目录中创建临时文件，验证上传、回读、重命名和删除，完成后移除测试文件。
4. 点击「立即备份并上传」，或为某个已有本地备份点击「上传云端」。只有加密上传并回读校验成功才更新最近云端成功时间。

要求服务支持 MKCOL、PROPFIND（Depth: 1）、PUT、GET、MOVE 与 DELETE，正常验证 HTTPS 证书。不自动跟随重定向；若网盘返回跳转，请填写最终 WebDAV 地址。

文件存放于指定地址下的 `AI-Control-Center/<设备标识>/`。云端名称使用随机任务标识，不暴露会话或项目目录。临时 `.partial` 不作为有效备份展示。不同设备可以读取所有设备的已完成副本，但不会合并数据库。

加密包版本为 1，使用 scrypt（N=32768、r=8、p=1）派生 AES-256-GCM 密钥；每包独立随机盐、nonce，包头经过认证。云端传输失败保留本地快照；丢失上传完成响应时复用原密文回读核对，避免重试产生重复副本。

Windows 桌面端使用 Electron safeStorage／DPAPI 保存网盘凭据和备份密码，经私有父子进程 IPC 读取。系统密钥存储不可用时降级为内存保存并在页面说明，绝不明文落盘。网页版密码只存在服务内存，重启后显示待解锁，需要重新输入。

## 自动备份

完成配置后勾选自动备份并保存。后端每 30 秒检查一次，按操作系统本地日期每日创建一次备份；首次执行等待初始来源同步完成。应用关闭后不常驻、不执行任务；再次启动只补做当天，不伪造关闭期间的历史快照。

网络故障最多自动重试三次，间隔为 1、5、15 分钟；认证、完整性或磁盘错误需处理后手动重试。停用自动备份后也停止后台重试，仍可手动重试。任务中断后保留失败状态；启用自动备份且已解锁时可继续上传重试。

本版不自动清理本地或云端历史副本。删除需要确认，仅删除选中的副本。任务、加密待上传包及非敏感配置存放在数据目录中，独立于业务 SQLite 数据库；它们不进入备份包。

## 换机恢复

新电脑安装应用后配置同一 WebDAV 地址和应用密码，填写原备份密码，保存并刷新云端列表。选择副本下载到本地，完成验证后从本地列表预览并恢复。如果该包使用旧密码，在「导入／远端恢复密码」中填写旧密码后下载。

默认验证使用合成数据和内存 WebDAV 协议测试，不连接开发者账户。真实网盘需通过「测试连接」和一次上传／下载恢复演练确认兼容性。

## GitHub 备份方案

GitHub 可以保存数据库备份，但本版尚未接入 GitHub 上传或自动备份。建议独立私有仓库，先用本地备份生成 SQLite 一致性快照，再用独立密码加密，最后作为 Release 附件上传。下载后应校验、解密并通过恢复预览验证。GitHub [Release 附件](https://docs.github.com/en/repositories/releasing-projects-on-github/about-releases)支持二进制文件，每个附件须小于 2 GiB；本应用备份包上限仍为 128 MiB。

普通下载的 `.aiccbackup` 包没有加密；完整数据库包含会话标题、标识和项目目录。不要将这些明文文件上传到公开源码仓库，也不要直接提交正在使用的 SQLite、WAL 或 SHM 文件。加密密码应在 GitHub 之外保存。现有 WebDAV 云上传已经提供加密与回读校验，可作为后续 GitHub 适配的基础。

## 接口

- 现有 `/api/backups` 和 `/:name/restore-plan`、`/:name/restore` 保持兼容。
- `GET /api/backups/:name/package` 下载普通包；`POST /api/backups/import` 接收二进制包，可通过 `x-backup-password` 传 UTF-8 密码的 Base64，仍需配对 Cookie 和 CSRF 请求头。
- `GET/PATCH /api/backup-settings` 读写配置，响应不包含密码；`POST /api/backup-settings/resume-sync` 恢复自动运行。
- `GET/POST /api/backup-jobs` 查询／创建任务，创建返回 202；kind 为 test、upload 或 download。`POST /api/backup-jobs/:id/retry` 重试。
- `GET /api/backup-remote` 列出正式包；`DELETE /api/backup-remote?id=…&confirm=true` 删除指定包。

所有新接口要求用户会话、禁止代理凭据，返回 no-store；恢复维护期间拒绝新的写操作。真实 Electron 验证覆盖本地完整操作和系统密钥存储，Windows CI 分别运行回归、桌面及性能验证。
