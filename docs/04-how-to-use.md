# v0.4 上手指南

1. 双击便携 EXE，等待自动配对；源码网页版运行 `npm run build`、`npm start`，打开终端地址并输入配对码。
2. 打开后先看到缓存，随后自动同步四个本机来源。无需为这些本机采集器配置 MCP 或 API Key。
3. 到「数据源」查看最近成功时间及状态。失败时展开原因并单独重试；未安装对应客户端不会影响其他来源。
4. DeepSeek 点击「读取历史导出」，输入包含官方 ZIP/CSV 的文件夹绝对路径，再点击「读取并统计」。本机会记住成功目录，不保存 API Key。
5. 点击来源图例或卡片「查看」筛选图表，点击「查看全部」恢复。未计入来源仍能独立查看，原因会保留显示；通用导入来源在「统计口径」中也有查看入口。
6. 总览的趋势范围只改变该趋势图。总览累计、模型排行为全部历史；缺失日期没有真实数值，实线连接不代表插补用量。会话、工作区、分析页的筛选则作用于这些页面全部指标。
7. 顶部刷新按钮重新同步本机来源。示例工作区只读；仅在已有示例数据时显示工作区切换。
8. 会话过期：网页重新输入终端当前配对码；桌面按 Alt 显示菜单，选择「应用 → 重新启动」。

点击「会话」按标题、会话标识或目录搜索，点击标题查看详情。点击「工作区」按实际项目目录查看投入；子目录及 Git worktree 分开展示。点击「分析」切换日／周／月和来源／模型，点击热力图单元格查看关联会话。筛选与分页写入地址，搜索词仅保留在当前页面状态；返回可恢复筛选。重启页面默认选择真实数据。

新明细固定为本机已记录用量，官方累计仍在总览。标题或目录没有明确元数据时显示未命名／未归属；DeepSeek 账单不生成会话。旧版本升级后同步一次建立明细索引，详细规则见 [会话与工作区](11-history-explorer.md)。

当前没有设置、记忆、自定义项目管理、额度或通用导入管理页面。旧后端接口保留供兼容使用，真实 MCP 客户端联调仍未完成。

数据位置、迁移、打包和验证见 [桌面说明](07-desktop.md)，统计口径见 [历史用量](06-usage-dashboard.md)。
